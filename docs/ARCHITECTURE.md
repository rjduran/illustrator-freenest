# Architecture

`NestPanel` uses the SDK `AIPanelSuite` for the host-owned dockable frame and embeds FreeNest-owned Win32 command buttons. The stable panel identifier allows Illustrator to associate it with workspace layouts. Window > FreeNest toggles visibility and reflects it with a menu checkmark. Panel callbacks enter an SDK application context before dispatching to the shared command handler. A guard disables the panel and blocks reentrant commands during modal operations. The panel is destroyed on the application-shutdown notification before SDK suites are released. Theme colors are queried from `AIUIThemeSuite`; embedded PNG arrays are generated from the original light/dark SVG artwork. No CEP runtime is added.

`native/Source/NestPlugin.cpp` implements the SDK plugin lifecycle, menu commands and Windows dialogs. It snapshots selected closed paths and object names, ignoring Illustrator layer containers while rejecting unsupported ordinary groups. Compound roots and selected children are normalized to one object; their original subpaths are retained for copying. The largest contour is the exterior; enclosed disjoint rings are classified using the compound fill rule. True holes are passed to the C API, included in filled-material/clearance validation, and excluded from label placement. Every duplicated compound subpath receives the same translation and rotation.

For supported single-path symbols, the plugin reads the definition contour and applies the instance transform before sending the outline to the solver. Unsupported definitions use a visible bounds rectangle. Output duplicates and transforms the linked instance, then checks the result against the planned contour or bounds.

The sheet-capture command stores a validated `Part` snapshot with its original curve segments and normalized polygon. The settings dialog selects a rectangle or that snapshot; rectangular output artboards use the sheet bounding dimensions. The solver receives the actual sheet polygon for each identical sheet. Custom-sheet results must pass independent polygon containment, edge-crossing and segment-distance checks before host edits. Drawing the optional boundary translates the original segments and handles, preserving curves. No captured Illustrator art handle is retained across commands or documents.

`NestCore` converts cubic Bézier geometry to bounded polygon approximations and calls the pinned OpenNest C ABI. Its code is independent of the Illustrator SDK, so the same solver adapter is compiled by the standalone native checks. It validates sheet containment, source assignments, rotation restrictions and spacing before host edits.

Compound search first checks whether any permitted part orientation could fit a hole bounding box with clearance. If none can, the solver receives outer outlines only; original hole geometry is retained for validation, output and labels. Otherwise an outer-outline baseline receives at most 20% of the time budget, capped at one second, and hole-aware search uses the remaining wall-clock budget. Every candidate is independently validated, then ranked by placed count, sheet count, placed material area and bounding footprint. A cancellation flag prevents starting the second pass after cancellation of the baseline. Upstream engine source remains unmodified.

The modal progress dialog starts a worker operating on copied geometry. A monotonic clock measures elapsed time; the solver budget provides an approximate countdown, and label throughput provides a labeling estimate. Atomic phase/counter values communicate progress; the estimate does not promise a hard completion deadline. Only the main thread calls Illustrator APIs. Cancellation is cooperative; the dialog waits for worker completion before releasing the engine or touching the document.

The output planner uses the source artboard as a reference and creates only used output sheets. Per-sheet local placements are mapped to each artboard's document origin. Original paths are duplicated; their anchors and both handles receive the same rigid placement, preserving the source stroke width. Failed output operations clean up newly created layers/artboards.

VDA labels come from the engine's two-pass `nfp_text_to_polylines` API. Label fitting keeps the engraving rectangle inside the flattened part, including stroke-width clearance. Labels receive the same transform as the part. Label routing selects a part group or a separate labels layer. Standalone grouped labeling changes the original hierarchy, and uses the SDK undo context for rollback on failure.

`NestUnits`, `NestOutput`, `NestSelection` and `NestLabelStyle` hold small host-independent policies. Tests cover numerical behavior, then independently check generated polygons/engraving strokes with Shapely. Host dialogs, artwork appearance and undo still need live Illustrator checks.

The SDK's own framework and PiPL generator are referenced from an external SDK installation. Generated `plugin.pipl` and binaries are ignored. OpenNest is fetched into ignored `vendor/OpenNest` at the revision in the dependency manifest; no SDK source or upstream engine source is copied into the tracked tree.

Output artboard planning reads the current document's maximum artboard bounds through AIDocumentSuite. It prefers the source's top row to the right, then wraps to lower rows anchored at the initial artboard's left edge. It never falls back to the canvas left edge or upper rows. Candidate wrapped row tops must be below the initial artboard, including when source-path bounds are part of the obstacle list. Placement reserves the full sheet-and-caption footprint, keeps clearance from existing artboards and selected source bounds, and preflights every position before document edits. The geometry-only planner is covered by tests for row wrapping, shifted origins and exhausted canvas.
