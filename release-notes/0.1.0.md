# FreeNest for Illustrator 0.1.0

## Features

- Nest closed paths and compound paths with holes on rectangular or captured irregular sheets.
- Choose Narrow strip, Compact area or Tight fit packing, permitted rotations, spacing and edge margins.
- Create multiple output artboards, wrap rows below the source, and optionally center finished layouts.
- Add single-stroke labels using Illustrator object names and OpenNest's bundled VDA font.
- Customize label size, font, color, stroke weight and layer placement; optionally label sheet boundaries.
- Use Object > FreeNest commands or the dockable Window > FreeNest panel.
- Preserve source artwork and report placed/unplaced paths and label results.

## Compatibility

- Windows x64, Adobe Illustrator 2024 (28.x).
- Other Illustrator versions and macOS are not verified.
- Install both FreeNest.aip and nfp_nest.dll together; see INSTALL.md in the download.

## Known limitations

- Packing is heuristic; a globally optimal layout is not guaranteed.
- Parts must be closed paths or compounds with one outer contour and disjoint holes. Ordinary groups, disconnected/nested material islands, open paths, clipping masks, live text and raster artwork are unsupported.
- Captured sheets must be simple closed paths without holes.
- Object-name labels support printable ASCII names up to 128 characters. Labels shrink to fit; unnamed, unsupported or too-small labels are skipped.
- Irregular-sheet centering is skipped when it would violate containment or edge clearance.
- Sheet labels are outside the artboard and may be omitted by artboard-only exports.
