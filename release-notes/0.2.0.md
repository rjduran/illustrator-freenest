# FreeNest for Illustrator 0.2.0

Pre-release for testing and feedback. Targets Illustrator 2024 (28.x) on Windows x64.

- Nest linked Illustrator symbol instances alongside closed paths and compound paths. FreeNest keeps the source instances and symbol definitions intact, and nested copies stay linked.
- Pack symbols made from one supported closed path, such as hexagons, by their actual contour. More complex symbols use their visible bounding rectangle. The completion report shows which method was used.
- Choose **30-degree steps** under **Permitted orientations** to let the solver try 12 orientations relative to the artwork's starting angle. The existing orientation choices are still available.
- Label symbols using the instance name or, if unnamed, the symbol definition name.

Contour spacing measures cut paths and excludes stroke width. A longer search or more angles do not guarantee a tighter layout. See INSTALL.md in the download for installation.
