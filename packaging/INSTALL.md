# Install FreeNest for Illustrator

Supported host: Adobe Illustrator 2024 (28.x), Windows x64.

1. Save your work and close Illustrator.
2. Extract the downloaded ZIP.
3. Copy **FreeNest.aip** and **nfp_nest.dll** together into Illustrator's `Plug-ins/Development` folder. Create the Development folder if needed. Administrator permission may be required.
4. Reopen Illustrator. Commands appear under **Object > FreeNest**. Open **Window > FreeNest** for the dockable command panel.

A typical installation folder is `C:\Program Files\Adobe\Adobe Illustrator 2024\Plug-ins\Development`.

To update, close Illustrator and replace both files with the pair from the new release. To uninstall, close Illustrator and remove those two files. The Illustrator SDK and Python are not required to use the compiled plugin.

Check **Object > FreeNest > About FreeNest** for the installed version. See RELEASE_NOTES.md for features and limitations. LICENSE and licenses/ contain the applicable project and third-party notices.
